# Nyx
### A chess engine built from the ground up.

Nyx is an open-source UCI chess engine focused on performance, experimentation, and the persuit of playing strength.

Check out our [website](https://engine-nyx.xyz/) for source, releases, live play, and more.

## Requirements

- A working C23 compiler

## Quickstart

```bash
$ # clone the repo
$ git clone https://engine-nyx.xyz/nyx/engine.git
$
$ # build and run the engine
$ make -C engine run
```
